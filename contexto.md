Herramienta de Trazabilidad - Proyecto de Grado📖 Descripción del ProyectoAplicación web diseñada para gestionar y documentar la trazabilidad en la elaboración de un proyecto de grado o texto científico. Su propósito principal es servir como un registro interactivo del proceso de escritura, ayudando al equipo de estudiantes a mantenerse organizados y permitiendo reflexionar sobre el progreso. Destaca por incluir un módulo especializado para auditar y justificar el uso de Inteligencia Artificial en la redacción académica.🎯 Usuarios ObjetivoPrincipal: Equipo de estudiantes que desarrolla el proyecto de grado.Secundario (Futuro): Profesores/Asesores para revisar el progreso y validar el uso adecuado de herramientas.🛠️ Stack TecnológicoFrontend: React.js + Tailwind CSS (para la interfaz de usuario moderna). Iconos de lucide-react.Backend: Python + FastAPI (para la creación rápida y robusta de la API).Base de Datos: PostgreSQL (usando SQLAlchemy como ORM para la interacción desde Python). Nota: El código actual está configurado temporalmente con SQLite para facilitar las pruebas locales inmediatas.🧩 Módulos Principales (Estructura de la Interfaz)Dashboard (Resumen): Panel general que muestra el porcentaje de avance del proyecto, cantidad de fases completadas y estadísticas de consultas de IA.Fases del Proyecto: Un cronograma interactivo. Permite crear etapas (ej. "Revisión Bibliográfica") y cambiar su estado (Pendiente, En Progreso, Completado) ajustando fechas límite.Bitácora de IA: Registro cronológico para la transparencia académica. Guarda:La herramienta usada (Gemini, ChatGPT, etc.).El "Prompt" o instrucción original.La respuesta cruda devuelta por la IA.Cómo se adaptó, parafraseó o utilizó esa información en el documento final.Recursos y Enlaces: Repositorio para clasificar y guardar URLs bibliográficas (PDFs, Google Scholar, carpetas compartidas de Google Drive).🗄️ Esquema de Base de Datos (Resumen)fases: id, title, status, target_date, created_atai_logs: id, tool, prompt, ai_response, usage_description, log_date, created_atrecursos: id, title, url, resource_type, description, added_date, created_at📍 Estado Actual del DesarrolloFase 1 (Completada): Prototipo de Frontend (React) 100% funcional con datos de prueba (mocks) y manejo de estados temporales para simular creación y edición.Fase 2 (Completada): Diseño de la base de datos relacional (PostgreSQL) y creación del archivo SQL de estructura.Fase 3 (Completada): Servidor Backend (FastAPI) codificado con rutas (GET/POST/PUT) para todos los módulos.Fase 4 (Pendiente): Integrar Frontend y Backend.
